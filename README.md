# Prometheus

把 B 站和 YouTube 视频整理成可以长期查阅的个人知识库的 Windows 桌面软件。

粘贴一个视频链接，Prometheus 会产出三样东西，并按同一套「分类 → 标题」归档：

- **精读报告**：沿用 [video-report-agent](https://github.com/imexlovery/video-report-agent) 的精读写作规则，在正文需要的位置插入视频截图；
- **思维导图**：参考 BiliSum 的写法，把报告提炼成知识树，每个要点都能跳回视频对应时刻；
- **字幕**：按时间戳完整保留原文。精读写完后，模型会参考报告改正同音错字、补全标点；原始识别结果随时可以切换查看，也能导出 SRT / TXT。

## 本地知识库：内容都存在哪里

所有内容都保存在你的电脑上。数据目录是首次启动时选择的文件夹，可以在「设置 → 其他 → 数据目录」里查看或更换。这个文件夹本身就是一个可以直接浏览的知识库：

```
<数据目录>\
├── llms.txt                 给 AI 的总目录（全部分类和条目）
├── index.json               全部条目的索引（标题、分类、标签、摘要、路径）
├── <分类>\
│   ├── _index.md            这个分类的目录
│   └── 2026-09-27 <报告标题>\
│       ├── 精读.html        精读报告：双击用浏览器打开，图片已内嵌
│       ├── 精读.md          报告的纯文字版，开头带标题、分类、标签、摘要
│       ├── 思维导图.md      导图大纲，可以导入 XMind、Obsidian 等软件
│       ├── 字幕.srt         带时间戳的字幕，播放器可以直接加载
│       ├── 字幕.txt         字幕纯文本，方便阅读和搜索
│       └── 来源.url         双击打开原视频
└── .prometheus\             软件内部数据（隐藏文件夹，请勿手动修改）
```

每样内容都有两份文件：

| 内容 | 软件里显示用的 | 知识库文件夹里给人和其他软件用的 |
|---|---|---|
| 精读 | `精读.html`（完整版式、图表和配图） | `精读.html`，另附纯文字的 `精读.md` |
| 思维导图 | 内部的知识树数据（节点、摘要、时间点、层级），支持折叠和点击跳转 | `思维导图.md` |
| 字幕 | 内部的逐句数据（每句的起止时间；纠错前的原文另存一份） | `字幕.srt`、`字幕.txt`（纠错后的版本） |

- 在软件里改分类名、移动或删除条目时，对应的文件夹会同步改名、移动或删除，索引也会随之更新。
- 如果在资源管理器里手动移动或删除了某个条目的文件夹，软件会提示「文件缺失」，并提供「删除记录」和「重新生成」两个选项。
- 任务完成后会自动清理下载的音视频和中间文件，每个视频通常只占约 2.5MB。
