# 配图规则（figures.md）

候选帧在当前工作区的 `frames/` 目录，清单是 `frames/frames.json`（含每帧的文件名、秒数与时间标签）。

1. 写每个大章节之前，先用 read 工具查看该章节时间范围内的候选帧，再决定是否配图。
2. 只选画面承载了正文没有的信息的帧：幻灯片、图表、公式板书、代码、软件界面、实物展示、地图。不选口播人像、转场、片头片尾、广告画面。
3. 每个大章节最多 1 张，全篇最多 12 张。没有合适的就不配，不为配图而配图。
4. 插在首次讨论该画面内容的段落之后，写法：

   ```html
   <figure class="report-figure" data-frame-t="332" data-source-units="...">
     <img src="frames/f_000332.jpg" alt="一句话描述画面">
     <figcaption>画面要点 · 05:32</figcaption>
   </figure>
   ```

   `data-frame-t` 是该帧在 frames.json 里的秒数；说明文字写画面里的关键信息，与正文互补、不重复。
5. **图片只用 `frames/...` 相对路径引用，不要自己转成 base64**——程序会在交付后自动内联。这是对 SKILL.md「自包含、无外部依赖」要求的唯一例外，必须遵守，否则输出会膨胀且可能失败。
6. 画面里的数字、文字与转写冲突时，核对后只写能确认的内容。
7. 其余所有规则（来源绑定、篇幅、措辞、商业推广排除）以 SKILL.md 和 standard.md 为准，配图不改变它们。
